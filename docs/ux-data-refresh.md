# 介面調整與資料整理

日期：2026-09-21（Asia/Taipei）。基準：`b026e5b`。實作 Sol。
範圍：介面與資料結構整理，不含新增旅遊事實。所有店址、分店、營業、航班、票券與庫存維持原狀，沒有任何項目從「待確認」改成已確認。

## 一、資料整理

### 公開文案搬回資料檔

`scripts/build.mjs` 原本用識別碼對照表寫死公開文案：`publicEventNote`、`publicStayNote`、`publicNotice`、`publicStoreNote` 四張表，加上 `publicRestaurantNotes` 以正規表示式改寫餐廳筆記（比對 `navermap`、`catchtable`、`安普賢推薦` 等字樣）。要改一句話得動建置程式，而且改寫規則散在條件式裡看不出來。

改為資料檔欄位，輸出文字與調整前逐字相同：

| 新欄位 | 檔案 | 取代 |
| --- | --- | --- |
| `publicNote` | days（event）、stays、stores | `publicEventNote`、`publicStayNote`、`publicStoreNote` |
| `publicTitle`、`publicContent` | notices | `publicNotice` |
| `publicNotes` | restaurants | `publicRestaurantNotes` |

原始欄位 `note`、`title`、`content`、`notes` 全部保留，供更新比對與資料追溯；公開頁面只讀新欄位，推薦出處與整理痕跡不會外流。

### 餐廳記錄類型改為明示

原本靠「有沒有 `image`」分辨兩種來源，判斷散在建置與測試各處。新增 `recordType`：

- `行程表`：原試算表整理的 17 筆，必須保留 `rawHours`。
- `截圖`：依截圖收錄的 6 筆，必須有 `image`；`rawHours` 原為「截圖未提供營業時間」這類佔位字串，改為 `null`。

`food-022` 的「貼文記載 24 小時」是實際記錄而非佔位字串，保留並改在卡片展開區顯示。

### 方位欄位拆開

`direction` 原本混著註解，例如 `西（沿用前一明示分組）`，建置時再用 `.slice(0, 1)` 取第一個字。拆成：

- `direction`：只存東、西、南、北、中或 `null`。
- `directionNote`：沿用上一列分組時的說明，否則 `null`。

### 購物欄位正名

`area` 實際存的是「貼文提及 Daiso」這類購買線索，不是地區，改名 `purchaseHint`。

### 驗證規則跟上

`scripts/validate-data.mjs` 新增檢查：`recordType` 只能是兩種值、行程表餐廳必須有 `rawHours`、截圖餐廳必須有 `image`、`direction` 只能是單一方位字或 `null`、`publicNotes` 必須是陣列，以及每筆 event、stay、store、notice 都必須有公開文案欄位。驗證訊息的筆數改為實際計算，不寫死。

## 二、介面調整

| 問題 | 處理 |
| --- | --- |
| 手機底部導覽用 `nth-child(6) { display: none }` 藏掉「資訊」，只能從首頁連結進入 | 底部列改六欄，六個分頁都直接點得到 |
| 七天入口在手機是橫向捲動，一次只看得到 2.5 天 | 手機改直向清單，七天一次看完 |
| 美食頁 23 張卡片平鋪，375 px 下約 9,990 px 高，沒有分段 | 餐廳依原清單的東西南北中分組（中 6、東 4、西 4、南 1、北 2），每組有標題與筆數 |
| 購物商品卡只剩品名與價格，規格、品牌與購買線索在先前精簡時被移除 | 卡片正面加回品牌、規格與價格，購買線索與備註收進展開區，卡片高度仍一致 |
| 日期頁籤沒有伺服器端預選，載入時七天同時攤開 | 建置時就選好第一天並收起其餘面板；另加 `<noscript>` 說明 |
| 切換日期後網址不變，重新整理會回到第一天 | 以 `replaceState` 同步 `?day=`，並支援 Home／End 鍵 |
| 長行程捲到一半無法換日 | 日期頁籤改為 sticky，切換後自動把該日帶進畫面 |
| 交通筆記顯示 `2026-09-24 16:55 → 2026-09-24 20:25` | 同日只寫一次日期：`9/24（四） 16:55 → 20:25`，跨日才兩邊都標 |
| 標題層級跳級（h3 分組底下出現 h2 卡片標題） | 卡片標題改用 `.card-title` 依所在區塊給層級；展開區的「餐點／注意事項／備註」改為標籤而非標題 |
| 字型以 CSS `@import` 載入，要等樣式表解析完才開始抓字型 | 改在 `<head>` 用 `preconnect` + `<link>` 載入 |
| `styles.css` 是一行壓縮字串，後續修正不斷往後追加，出現重複與互相覆蓋的規則 | 重寫為分段、有註解的樣式表；合併重複的斷點；間距與圓角改由設計權杖控制 |

另補上 `og:` 分享標籤、`color-scheme: light`，並把狀態標籤字級從 .68rem 調到 .72rem。

沒有重新加入先前已驗收移除的文字搜尋與分類下拉；分組只是靜態排版，不是互動篩選。
