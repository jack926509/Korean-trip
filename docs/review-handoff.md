# Astra 獨立驗收交接

## 宣稱完成的範圍

- 六頁靜態網站與手機底部導覽。
- 7 天暫定行程、17 筆餐廳、3 筆景點、7 筆商店、6 筆交通、2 筆住宿與 3 筆提醒。
- 景點、美食與購物直接顯示全部卡片；文字搜尋與分類查找已依使用者要求移除。日期切換及行程／資料頁互連保留。
- 購物商品空狀態；資料新增後建置器可顯示商品卡。
- 韓紙暖白、墨色、朱紅與靛藍的旅行手冊視覺。

## 驗收指令

```bash
npm run check
python3 -m http.server 4173 -d dist
```

## 驗收重點與風險

- 375 px 與桌面版六頁不得水平溢出或遮擋；手機主導覽顯示五個核心入口，資訊從首頁可進入。
- `food-015` 與 `food-002` 必須由行程精確連回餐廳；其他模糊餐點不可誤配。
- 兩筆山清烤肉必須保留；`food-011` 的 `11:300` 需原樣顯示。
- Google Fonts 是唯一外部樣式資源；無網路時會使用本機 serif fallback，不影響功能。
- 行程、餐廳、商店與交通尚未逐項官方查證，頁面必須保持待確認語意。
- 原始購物商品仍為空；可在臨時副本加入商品驗證渲染，但不可提交測試商品。
