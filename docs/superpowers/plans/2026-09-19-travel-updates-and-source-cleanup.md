# 最新旅遊摘要與公開來源清理 Implementation Plan

**Goal:** 移除網站可見的試算表與整理痕跡，並在實用資訊頁加入 4 張官方旅遊摘要卡。

**Architecture:** 內部 `data/sources.json` 與餐廳 raw 欄位繼續保留追溯；新增 `data/travel-updates.json` 存放可公開的官方旅遊參考。建置器只輸出旅客需要的時間、提醒、餐點、候選建議與官方旅遊資訊連結。
