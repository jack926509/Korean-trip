## 驗收條件與處理

兩頁圖片須在卡片內、標籤不被遮擋，桌面與 375 px 手機不得水平溢出。
先確認正式站問題，再修正 CSS 資產版本與圖片間距，最後執行自動測試、瀏覽器驗收及獨立審查。

正式站瀏覽器 CSSOM 缺少 `.reference-image` 規則，仍有已移除的 `.filter-bar` 規則；同時直接讀取正式站 CSS 已有圖片規則。瀏覽器使用了舊 CSS，導致 1,206 px 原圖超出 368 px 卡片，1280 px 視窗的頁面寬度達 2069 px。

建置時依 CSS 內容產生 SHA-256 前 12 碼的檔名，六頁一律引用該檔；原固定檔名仍保留相容。圖片上方負邊距歸零，保留標籤下方間距。資料與原圖未修改。
